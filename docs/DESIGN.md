# Design System

## Core Experience
- dreamy otome-game mood
- dark polished phone shell
- pink / violet / blue accent structure
- soft glassmorphism cards
- highly legible Japanese typography

## Base Tokens
All main visual values are centralized in:
`frontend/src/styles/base/variables.css`

## Page Hierarchy
- Home = overview and entry
- Friends = character selection with hierarchy
- Call = most premium page, highest polish
- Summary = emotional wrap-up + memory feedback
